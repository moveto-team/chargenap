팀 Moveto · 2026년 11월 12일

> 이 문서는 현대자동차그룹 차량용 앱 개발 공모전 접수양식 "02 앱 프로젝트 소개 / 심사 자료"의 1~8번 항목 순서를 그대로 따릅니다. 작성·제출용 접수양식(DOCX)은 이 내용으로 채웠습니다. 양식 규정에 따라 구성원의 성명·연락처·소속은 적지 않습니다.

## 1. 앱 한 줄 소개

전기차 급속 충전 시간에 맞춰 운전석 시트와 공조를 자동으로 세팅하고, 충전이 끝나기 전에 깨워 주는 차량용 파워냅 앱입니다.

---

## 2. 기획 배경

**고객이 불편한 순간: 급속 충전기 앞에서 아무것도 못 하고 기다리는 수십 분.**

- **충전 대기는 길다.** 서울시 급속 충전기는 1회당 평균 47.2분 이용됩니다(김수재, 「전기자동차의 충전시설 이용현황 및 이용 영향요인 분석」, 한국ITS학회논문지 23(5), 2024). 운전자는 대부분 그 시간을 차 안에서 휴대폰을 보며 보냅니다.
- **쉬려면 손이 많이 간다.** 시트를 눕히고, 공조를 맞추고, 충전이 끝나는 시각을 계산해 알람을 맞추는 일을 매번 직접 해야 합니다. 그래서 피곤해도 쉬지 않고 기다리기만 합니다.
- **잠들면 충전 완료를 놓친다.** 국내 급속 충전기는 전체 충전기의 10.9%(58,398기)뿐이라 급속 충전기 1기를 전기차 약 19대가 나눠 쓰는 수준입니다(충전 사업자 워터 분석, 헬로티 2026.09.16). 충전이 끝난 뒤에도 자리를 차지하면 다른 운전자의 대기가 길어집니다.
- **피로는 그대로 다시 운전대로 간다.** 급속 충전은 주로 고속도로 휴게소 등 장거리 이동 중에 합니다(고속도로 휴게소 급속 충전기는 일반 급속 충전소보다 이용 횟수가 평균 약 3.7배 많음, 채비 분석, ZDNet Korea 2026.11.03). 충전이 끝나면 곧바로 다시 장시간 운전을 해야 합니다. 최근 3년(2023~2025) 7월 고속도로 사망사고 사망자의 약 83%가 졸음운전·전방주시 태만에서 나왔고(한국도로공사 분석, 뉴시스 2026.07.07), 고속도로 졸음운전 사고의 치사율은 18.5%로 과속 사고보다 높습니다(한국도로공사, 2012~2016년 집계).

**왜 해결해야 하는가: 짧은 낮잠은 운전 재개 전 각성도를 실제로 회복시킵니다.**

- NASA 장거리 조종사 연구(Rosekind 외, NASA TM-108839)에서 평균 약 26분을 잔 조종사는 쉬지 않은 조종사보다 생리적 각성도와 수행 능력이 높았고, 그 효과가 착륙 단계까지 이어졌습니다. Sleep Foundation은 이를 "각성도 최대 54%, 업무 수행 34% 향상"으로 소개합니다.
- 다만 30분을 넘는 낮잠은 깬 뒤 멍한 상태(수면 관성)를 일으킬 가능성이 커집니다(Sleep Foundation, 2025). 그래서 차지냅은 10~25분을 추천하고, 연장해도 총 30분을 넘기지 않습니다.

충전 대기는 이미 정차해 있고, 끝나는 시각을 차가 알고 있고, 끝나면 곧바로 운전이 시작되는 시간입니다. **"충전하는 동안 제대로 쉬고, 충전이 끝나기 전에 개운하게 깨는 것"을 차가 알아서 해 주면** 대기 시간이 휴식이 되고, 휴식이 안전 운전으로 이어집니다.

## 3. 앱 주요 기능 및 차량 특화 요소

### 주요 기능

| 기능 | 내용 | 해결하는 문제 |
| --- | --- | --- |
| 충전 연동 세션 추천 | 충전 시작과 기어 P를 감지하면 남은 충전 시간을 계산해 먼저 제안합니다. 추천 = min(남은 충전 시간 − 5분, 25분)을 5분 단위로 내린 값. 남은 시간이 10~14분이면 호흡 5분, 10분 미만이면 제안하지 않습니다. | 알람 시각 계산이 필요 없음 |
| 원터치 캐빈 세팅 | 현재 운전석 등받이·공조를 기억한 뒤 등받이를 눕히고 수면용 온도·풍량으로 바꿉니다. 끝나면 원래대로 되돌립니다. | 손으로 하던 준비를 한 번에 |
| 수면 가이드 | 호흡 안내 음성 2분 → 백색소음. 화면 밝기를 최소로 낮춥니다. | 짧은 시간에 잠들기 |
| 스마트 기상 | 타이머 종료와 "충전 완료 5분 전" 중 먼저 오는 시점에 서늘한 바람 → 시트 복귀 → 음성 브리핑(배터리·주행 가능 거리·쉰 시간) 순으로 깨웁니다. 충전이 중단·완료되면 즉시 깨웁니다. | 충전 완료를 놓치지 않음 |
| 안전 가드 | 기어 P가 확인돼야 시작합니다. 시트는 "뒷좌석에 사람·짐 없음"을 확인한 뒤에만 운전석만 움직입니다. 도어가 열리면 시트를 즉시 멈추고, 기어가 바뀌면 즉시 중단·복구합니다. | 시트 자동 이동의 위험 차단 |
| 음성 조작 | "20분만 재워줘", "5분 더", "깨워줘", "몇 분 남았어?", 뒷좌석 질문에 "없어요/있어요". 음성을 못 쓰면 터치로 전부 조작할 수 있습니다. | 누운 채 조작 |
| 휴식 리포트 | 주간 휴식 횟수·시간, 요일별 그래프, 최근 세션 기록 | 반복 사용 동기 |

### 차량 특화 요소 — 스마트폰 앱으로는 만들 수 없는 이유

| 요소 | 스마트폰 알람·수면 앱 | 차지냅 |
| --- | --- | --- |
| 세션 길이 | 사용자가 충전 종료 시각을 계산해 입력 | 차량 배터리 잔량 변화로 남은 충전 시간을 계산하고, 충전 속도가 바뀌면 기상 시각을 다시 계산 |
| 시작 시점 | 사용자가 앱을 열어야 함 | 충전 시작과 기어 P를 감지해 차가 먼저 제안 |
| 휴식 환경 | 시트·공조를 손으로 조작 | 운전석 등받이와 공조를 자동 세팅하고 끝나면 원래 값으로 복구 |
| 기상 방식 | 소리 알람 | 바람·시트·음성의 단계적 기상, 배터리·주행 가능 거리 브리핑 |
| 안전 | 차량 상태를 모름 | 기어·도어(가능한 차량은 주차 브레이크)와 연동, 조건이 깨지면 즉시 중단·복구 |
| 조작 | 화면 터치 | 누운 채 음성으로 조작 |

**정차 맥락과의 결합.** 차지냅은 충전 중 정차 상태(기어 P)에서만 실행되고 주행 중에는 시작할 수 없습니다. 휴식이 끝나는 순간이 곧 주행을 다시 시작하는 순간이므로, 각성도 회복이 안전 운전으로 바로 이어집니다.

## 4. 주요 사용 시나리오

**누가:** 주말에 서울에서 부산으로 가는 전기차 운전자. 3시간을 운전해 휴게소 급속 충전기에 차를 댔고, 졸리다.

1. **제안 (충전 시작 직후).** 충전을 시작하고 기어를 P에 두면, 차지냅이 먼저 말합니다. "80%까지 약 27분 남았어요. 20분 파워냅 어때요?"
2. **수락.** 운전자는 "20분만 재워줘"라고 말하거나 화면의 [시작]을 누릅니다.
3. **안전 확인.** 차지냅이 기어 P·충전 중·도어 닫힘을 확인하고(주차 브레이크는 읽을 수 있는 차량에서만) 묻습니다. "뒷좌석에 사람이나 짐이 있나요?" → "없어요". "있어요"라고 하거나 답이 없으면 시트는 그대로 두고 공조와 소리만으로 쉬게 합니다.
4. **캐빈 세팅.** 지금 등받이·공조 값을 기억한 뒤 운전석 등받이를 설정한 만큼(기본 60%) 눕히고, 23℃·약한 바람으로 바꿉니다. 화면이 어두워집니다.
5. **수면.** 호흡 안내 음성 2분 뒤 백색소음으로 넘어갑니다. 차지냅은 충전 상태와 기어·도어를 계속 지켜봅니다. 남은 시간이 궁금하면 "몇 분 남았어?", 더 자고 싶으면 "5분 더"(충전 완료 5분 전·총 30분 이내에서만 허용).
6. **기상.** 타이머가 끝나기 전에 충전이 거의 끝나면 그때 깨웁니다. 서늘한 바람 → 등받이 원위치 → "배터리 80퍼센트, 주행 가능 거리 360킬로미터예요. 20분 쉬셨어요."
7. **출발.** 운전자는 개운한 상태로 충전기를 비워 주고 출발합니다. 세션은 주간 휴식 리포트에 쌓입니다.

**예외 상황**

| 상황 | 차지냅의 동작 |
| --- | --- |
| 수면 중 동승자가 문을 엶 | 시트 이동을 즉시 멈추고 세션을 중단, "문을 닫으면 시트를 되돌릴게요" 안내 후 닫히면 복구 |
| 누군가 기어를 D로 바꿈 | 즉시 중단하고 시트·공조를 원래대로 복구 |
| 충전기가 멈춤(충전 중단) | 즉시 깨우고 브리핑에서 충전 중단을 알림 |
| 남은 충전 시간을 아직 모름(충전 직후) | 15분/20분 중 고르게 하고 타이머로 동작, 잔량이 오르기 시작하면 기상 시각을 다시 계산 |
| 시트를 지원하지 않는 차종 | 공조와 소리만으로 진행 |

| 구분 | 고객 | 사용 상황 |

## 5. 개발 계획

### 개발 범위와 현재 상태 (2026-11-12 기준)

1차 접수 시점에 **MVP 전체(위 7개 기능)가 동작하는 앱**을 구현했습니다. 소스와 release APK는 GitHub 저장소에 있습니다.

| 영역 | 상태 |
| --- | --- |
| 세션 엔진(상태 머신·충전 시간 추정·안전 가드) | 구현, 단위 테스트로 검증 |
| 차량 연동(Pleos Vehicle SDK) | 구현. Pleos Connect Emulator 2.1.0에서 설치·실행과 SDK 연결 요청까지 확인. 실제 차량 값 읽기·시트·공조 제어의 에뮬레이터 실행 검증은 2차 PT 전 과제(개발 PC 에뮬레이터의 차량 서비스 미기동) |
| 음성(TTS·STT) | 구현, 명령 해석·대화 흐름은 단위 테스트로 검증. 에뮬레이터에 온디바이스 음성 엔진이 없어 실행 검증은 2차 PT 전 과제(음성이 없어도 터치로 전부 조작) |
| 화면 7종(홈·안전 확인·수면·기상/브리핑·중단 안내·휴식 리포트·설정) | 구현, 2,560×1,440 화면에서 확인 |
| 데모 모드(가상 차량, 30배속) | 구현. 실제 차량 연결이 안 되는 환경에서도 전체 흐름을 볼 수 있고, 화면 상단에 "DEMO" 배지를 띄워 실제 연동과 구분 |

| 기능 | SDK · API | 사용 방식 | 권한 |

| 시트 리클라인·복구 | Vehicle SDK · Seat | 운전석 등받이 위치를 기억하고, 방향 이동(`moveSeatBackrestAngle`)을 보낸 뒤 위치 구독으로 목표에서 정지. 끝나면 기억한 위치로 복구 | `pleos.car.permission.CAR_SEATS`, `CONTROL_CAR_SEATS` |

| 도어 감시 | Vehicle SDK · Door | 도어 위치를 구독해 열리면 시트 정지·세션 중단 | `pleos.car.permission.CAR_DOORS` |
| 주행 가능 거리 | Vehicle SDK · Odometer | 기상 브리핑에 표시 | `pleos.car.permission.CAR_DRIVE` |
| 음성 안내 | TextToSpeech SDK 3.3.1 (온디바이스) | 제안·안전 질문·호흡 안내·기상 브리핑 | `pleos.car.permission.TTS_SERVICE` |
| 음성 명령 | SpeechToText SDK 3.3.1 (온디바이스) | 한국어 규칙 기반 명령 해석("재워줘", "5분 더", "깨워줘" 등) | `pleos.car.permission.STT_SERVICE` |

### 구현 구조

| 계층 | 역할 |
| --- | --- |
| 차량 연동(`vehicle/`) | SDK 호출을 `VehicleGateway` 한 곳에 모으고 차종별 지원 여부(`checkXXXCapabilities`)를 판단. 콜백 API를 코루틴으로 감싸고 모든 호출에 타임아웃. 가상 차량 구현으로 데모·테스트 |
| 세션 엔진(`session/`) | 대기 → 제안 → 안전 확인 → 캐빈 세팅 → 수면 → 기상 → 브리핑 상태 머신, 충전 시간 추정기, 안전 가드. Android 의존성이 없는 순수 Kotlin |
| 음성(`voice/`) | STT·TTS 래퍼, 질문 맥락별 한국어 명령 해석기("없어요"가 뒷좌석 질문과 제안 응답에서 다르게 해석됨), 백색소음 생성 |
| 화면(`ui/`) | Jetpack Compose 화면 7종, 어두운 테마, 76dp 이상 터치 영역, 누운 자세에서도 읽히는 큰 글자 |
| 포그라운드 서비스 | 세션 중 다른 앱으로 화면을 바꿔도 감시·기상 타이머가 멈추지 않게 유지 |

### SDK 특성에 맞춘 설계

- **차종별 지원 편차:** 시트·공조 capability가 없으면 해당 항목은 건너뛰고 나머지로 진행합니다.
- **비동기 결과 확인:** 공조 설정은 완료 콜백만 믿지 않고 값을 다시 읽어 반영을 확인합니다. 시트는 절대 각도 지정 API가 없어 위치를 지켜보다 정지 명령을 보내고, 방향이 반대거나 응답이 없으면 즉시 멈춥니다.
- **값을 못 읽을 때는 안전한 쪽으로:** 기어를 확인하지 못하면 시작하지 않고, 수면 중 값이 잠시 끊기는 것(읽기 실패)은 "기어 변경"으로 보지 않습니다.

## 6. 기대효과 및 발전 가능성

### 사용자에게 주는 가치

- **대기 시간이 휴식 시간으로:** 급속 충전 1회 평균 47분 중 20분 안팎을 버튼 한 번(또는 한마디)으로 쉬는 시간으로 바꿉니다.
- **충전 후 안전 운전:** 출발 직전에 짧게 자고 개운하게 깨도록 설계해, 장거리 운전 중 졸음운전 위험을 줄이는 데 기여합니다.
- **충전기 회전율:** 충전 완료 전에 깨우므로 충전이 끝난 차가 자리를 오래 차지하지 않습니다.

### 타깃 시장

- 국내 전기차 누적 등록은 2026년 6월 말 1,095,218대입니다(국토교통부, M이코노미뉴스 2026.07.30). 전기차 보유자는 월 평균 9회 충전합니다(컨슈머인사이트 조사, 데일리카 2025.12.02).
- Pleos Connect는 2026년 5월 출시된 더 뉴 그랜저에 처음 적용됐고(출시 첫날 10,277대 계약, 디지털데일리 2026.05.15), 현대자동차그룹은 2030년까지 글로벌 약 2,000만 대에 탑재할 계획입니다(머니투데이·현대차그룹 뉴스룸 2026.04.30).

### 예상 MAU

MAU = Pleos Connect 탑재 전기차 수 × 월 1회 이상 급속 충전하는 비율 × 앱 설치율 × 설치자 중 월간 사용 비율

| 시점 | 탑재 전기차 | 월 1회 이상 급속 충전 | 설치율 | 월간 사용 | 예상 MAU |
| --- | --- | --- | --- | --- | --- |
| 출시 1년 차 | 10만 대 | 40% | 15% | 50% | 3,000명 |
| 출시 3년 차 | 50만 대 | 40% | 20% | 50% | 20,000명 |

입력값의 근거와 한계:

- **탑재 전기차:** 2030년 2,000만 대 탑재 계획 중 전기차 비중과 연도별 보급 속도는 공개되지 않아 팀의 가정입니다.
- **급속 충전 비율 40%:** 전기차 이용자의 주 충전 방식은 완속(63.7%, EV트렌드코리아 2026 조사, 오토레이싱 2026.08.21)이므로, 월 1회 이상 급속 충전하는 비율은 절반 아래로 보수적으로 잡았습니다(가정).
- **설치율·월간 사용률:** 차량 앱마켓 설치율의 공개 수치가 없어 팀의 가정입니다. 충전을 시작하면 앱을 열지 않아도 제안이 뜨는 구조라, 설치 후 사용률을 50%로 보았습니다.

### 리텐션(Retention)

30일 리텐션 35%를 목표로 합니다(가정). 근거가 되는 구조는 다음과 같습니다.

- **자동 제안:** 충전을 시작하면 차가 먼저 제안하므로 충전 습관이 곧 사용 습관이 됩니다(월 평균 충전 9회가 모두 재방문 기회).
- **휴식 리포트:** 주간 휴식 횟수·시간을 보여 줘 꾸준한 사용을 유도합니다.
- **모드 확장(계획):** 낮잠이 필요 없는 날에도 쓸 수 있도록 호흡·스트레칭·명상 모드를 넓힙니다.

### 수익 모델

| 모델 | 내용 | 대상 |
| --- | --- | --- |
| 프리미엄 구독 | 수면·명상 콘텐츠와 사운드 팩(앱마켓 인앱 구매) | 개인 운전자 |
| 충전 사업자 제휴 | 충전 대기 만족도 개선 기능을 충전 서비스와 묶어 제공 | 충전 사업자 |
| 제휴 쿠폰 | 기상 직후 휴게소·카페 쿠폰 제안 | 휴게소, 프랜차이즈 |

### 확대 계획

1. **1단계(출시):** Pleos App Market 입점, 파워냅 기능으로 초기 사용자 확보.
2. **2단계:** 경로 연계 예약(NaviHelper SDK로 경로상 충전 계획을 읽어 휴게소 도착 전에 파워냅을 예약), 호흡·스트레칭·명상 모드.
3. **3단계:** 충전 사업자 연동(충전 완료 알림·자리 비움 연계), 직업 운전자용 피로 관리, Pleos Connect 적용 지역을 따라 해외 확대.
