# 차지냅(ChargeNap) 서비스 기획서

작성일 2026년 11월 11일, 정정 2026년 11월 12일

차지냅은 전기차 급속 충전 시간에 맞춰 시트와 공조를 자동으로 세팅하고, 충전이 끝나기 전에 깨워 주는 차량용 파워냅 앱입니다. 현대자동차그룹 차량용 앱 개발 공모전 접수 마감은 2026년 11월 15일 23:59이며, 아래 내용을 접수양식(DOCX)의 해당 항목에 옮겨 적으면 됩니다.

## 1. 서비스 개요

차지냅은 충전 중인 20~40분을 버튼 한 번으로 잠들고 충전 완료 전에 깨는 시간으로 바꿉니다.

## 2. 문제 정의와 타깃 고객

전기차 운전자는 급속 충전 한 번에 수십 분을 차 안에서 보내지만, 그 시간을 제대로 쉬는 데 쓰지 못합니다.

### 페인포인트

1. 충전 시간은 길고 쓸모가 없습니다. 서울시 급속 충전기는 1회당 평균 47.2분 이용됩니다(한국ITS학회논문지, 2024). 대부분 스마트폰을 보며 기다립니다.
2. 쉬려면 손이 많이 갑니다. 시트를 눕히고, 공조를 맞추고, 충전 종료 시각을 계산해 알람을 맞추는 일을 매번 직접 해야 합니다.
3. 충전이 끝난 줄 모르고 잡니다. 급속 충전기 1기를 전기차 약 19대가 나눠 쓰는 상황에서(헬로티, 2026.09), 충전 완료 후 자리 점유는 다른 운전자의 대기로 이어집니다.
4. 장거리 운전의 피로가 쌓입니다. 급속 충전은 주로 장거리 이동 중에 하므로, 충전 직후 다시 장시간 운전해야 합니다.

### 해결 근거

짧은 낮잠은 운전 재개 전 각성도를 회복시킵니다. NASA의 1995년 조종사 연구에서 평균 26분 낮잠은 각성도를 최대 54%, 업무 수행을 34% 높였습니다(Sleep Foundation). 30분을 넘기면 깊은 잠에 들어 깬 뒤 멍한 상태(수면 관성)가 생기므로, 차지냅은 10~25분을 추천하고 연장해도 30분을 넘기지 않습니다.

### 타깃 고객

| 구분 | 고객 | 사용 상황 |
| --- | --- | --- |
| 핵심 | 장거리 이동 중 급속 충전을 월 2회 이상 하는 EV 운전자 | 고속도로 휴게소, 출장·주말 이동 |
| 확장 1 | 택시·화물 등 운행 시간이 긴 EV 직업 운전자 | 근무 중 충전 대기 |
| 확장 2 | 충전 중 차 안에서 기다리는 일반 운전자 | 마트·도심 급속 충전 (명상·스트레칭 모드, 확장 계획) |

국내 전기차 누적 등록은 2026년 6월 말 109만 5,218대입니다(M이코노미뉴스, 국토교통부 통계 인용).

## 3. 핵심 기능과 사용 시나리오

운전자는 "20분만 재워줘" 한마디만 하면 되고, 나머지는 차가 처리합니다.

### 사용 시나리오

1. 제안. 충전 시작과 기어 P를 감지하면 "80%까지 약 27분 남았어요. 20분 파워냅 어때요?"라고 먼저 묻습니다.
2. 시작. 운전자가 음성("20분만 재워줘") 또는 터치 한 번으로 수락합니다.
3. 안전 확인. 기어 P, 도어 닫힘, 충전 중 여부를 확인합니다(주차 브레이크는 읽을 수 있는 차량에서만 확인). 시트를 움직이기 전에 뒷좌석에 사람이나 짐이 있는지 음성으로 묻고, "없어요"라고 답해야 시트를 움직입니다.
4. 캐빈 세팅. 현재 시트·공조 상태를 저장한 뒤 시트를 눕히고 수면용 온도·풍량으로 바꿉니다. 화면은 어두워집니다.
5. 수면. 호흡 안내 음성 2분 뒤 백색소음으로 넘어갑니다. 충전 상태는 계속 감시합니다.
6. 기상. 타이머 종료와 충전 완료 5분 전 중 먼저 오는 시점에 깨웁니다. 서늘한 바람, 시트 복귀, 음성 브리핑("배터리 80%, 주행 가능 거리 ○km") 순서입니다.
7. 기록. 세션 시간과 충전량을 저장해 주간 휴식 리포트로 보여 줍니다.

### 세션 길이 규칙

추천 시간은 "남은 충전 시간 − 5분"과 25분 중 짧은 쪽을 5분 단위로 내린 값입니다. 남은 충전 시간이 10~14분이면 낮잠 대신 호흡 5분 모드를 제안하고, 10분 미만이면 제안하지 않습니다. 남은 충전 시간을 추정할 수 없으면 15분과 20분 중 고르게 하고 타이머로만 동작합니다.

## 4. 차량특화성

차지냅의 핵심 기능은 모두 차량 데이터를 읽거나 차량을 제어해야 동작하므로 스마트폰 앱으로는 만들 수 없습니다.

| 요소 | 스마트폰 알람·수면 앱 | 차지냅 |
| --- | --- | --- |
| 세션 길이 | 사용자가 충전 종료 시각을 계산해 입력 | 충전 상태를 읽어 자동 산정, 충전 속도가 바뀌면 기상 시각 재조정 |
| 시작 시점 | 사용자가 앱을 열어야 함 | 충전 시작과 기어 P를 감지해 먼저 제안 |
| 휴식 환경 | 시트·공조를 손으로 조작 | 시트 리클라인과 공조를 자동 세팅하고 끝나면 복구 |
| 기상 방식 | 소리 알람 | 공조·시트·음성의 단계적 기상, 배터리·주행 가능 거리 브리핑 |
| 안전 | 차량 상태를 모름 | 기어·도어(가능한 차량은 주차 브레이크)와 연동, 조건이 깨지면 중단 |
| 조작 | 화면 터치 | 누운 채 음성으로 조작 |

정차 맥락과의 결합. 차지냅은 충전 중 정차 상태에서만 실행되고 주행 중에는 시작할 수 없습니다. 휴식이 끝나는 시점이 곧 주행 재개 시점이므로, 각성도 회복이 안전 운전으로 바로 이어집니다.

## 5. 기술 활용 계획

차지냅은 Vehicle SDK의 6개 API 그룹(EvBattery, Gear, Odometer, Seat, HVAC, Door)과 음성 SDK 2종을 핵심 흐름에 사용합니다.

| 기능 | SDK · API 그룹 | 사용 방식 | 권한 |
| --- | --- | --- | --- |
| 충전 감지, 잔량 조회 | Vehicle SDK · EvBattery (보조: AAOS Car API) | 잔량(%)을 구독하고, 충전 스위치 조회와 충전 포트 열림 조회로 충전 중 여부를 추론합니다. AAOS `EV_CHARGE_STATE`·`EV_CHARGE_PORT_CONNECTED`를 읽을 수 있는 차량에서는 그 값을 우선 사용합니다. | `pleos.car.permission.CAR_ENERGY` (AAOS 사용 시 `android.car.permission.CAR_ENERGY`(런타임 요청), `android.car.permission.CAR_ENERGY_PORTS`) |
| 남은 충전 시간 | Vehicle SDK · EvBattery, 앱 내 추정기 (보조: AAOS Car API) | SDK가 남은 충전 시간을 제공하지 않으므로 잔량 변화 속도(지수이동평균)와 목표 잔량(앱 설정, 기본 80%)으로 추정합니다. AAOS `EV_CHARGE_TIME_REMAINING`을 읽을 수 있으면 그 값을 우선합니다. | `pleos.car.permission.CAR_ENERGY` (AAOS 사용 시 `android.car.permission.CAR_ENERGY`) |
| 주차 상태 확인 | Vehicle SDK · Gear (보조: AAOS Car API) | 기어 P 여부를 읽습니다. 주차 브레이크는 Vehicle SDK가 주지 않으므로 AAOS `PARKING_BRAKE_ON`을 읽을 수 있을 때만 확인하고, 못 읽으면 기어 P만으로 판정합니다. 기어를 SDK로 읽지 못할 때는 AAOS `GEAR_SELECTION`으로 대체합니다. | `pleos.car.permission.CAR_DRIVE` (AAOS 사용 시 `android.car.permission.CAR_POWERTRAIN`) |
| 주행 가능 거리 | Vehicle SDK · Odometer | 주행 가능 거리(단위 m)를 읽어 km로 바꿔 기상 브리핑에 표시합니다. | `pleos.car.permission.CAR_DRIVE` |
| 시트 리클라인·복구 | Vehicle SDK · Seat | 운전석 등받이 위치를 저장합니다. 절대 각도 지정 API가 없으므로 방향 이동(`moveSeatBackrestAngle`)을 보내고 위치 구독으로 목표에 닿으면 정지시키며, 종료 후 저장한 위치로 복구합니다. | `pleos.car.permission.CAR_SEATS`(조회·구독), `pleos.car.permission.CONTROL_CAR_SEATS`(이동) |
| 공조 프리셋 | Vehicle SDK · HVAC | 온도(℃)와 풍량(정수 단계)을 조회·저장하고 수면 프리셋을 설정한 뒤 종료 후 복구합니다. | `pleos.car.permission.CAR_CLIMATE`(조회·구독), `pleos.car.permission.CONTROL_CAR_CLIMATE`(설정) |
| 도어 감시 | Vehicle SDK · Door | 도어 열림 값을 구독해 열리면 시트 이동을 멈추고 세션을 중단합니다. | `pleos.car.permission.CAR_DOORS` |
| 음성 안내, 기상 브리핑 | TextToSpeech SDK 3.3.1 | 호흡 안내, 기상 멘트, 충전 결과를 온디바이스 모드로 읽어 줍니다. | `pleos.car.permission.TTS_SERVICE` |
| 음성 명령 | SpeechToText SDK 3.3.1 | "재워줘", "5분 더", "깨워줘"를 온디바이스 모드로 인식합니다. | `pleos.car.permission.STT_SERVICE` |
| 경로 연계 (확장 계획, 미구현) | NaviHelper SDK | 경로상 충전 계획을 조회해 세션을 예약하는 확장 계획입니다. 이번 구현 범위에 포함하지 않습니다. | 해당 없음 |

### 구현 시 고려한 SDK 특성

- 차종별 지원 편차. Vehicle SDK는 차종에 따라 일부 기능만 지원합니다. 각 API 그룹의 `checkXXXCapabilities`로 확인하고, 시트 제어가 안 되는 차종에서는 공조와 사운드만으로 동작합니다.
- 비동기 호출. 차량 통신은 onComplete/onFailed 콜백으로 결과가 오므로, 캐빈 세팅을 단계별 상태로 관리하고 실패 시 해당 단계만 건너뜁니다. 모든 호출에 타임아웃을 두고, 완료 콜백만으로 적용됐다고 보지 않고 값을 다시 읽어 확인합니다.
- 충전 상태. Vehicle SDK 2.3.2에는 충전 상태 변화를 구독하는 API가 없습니다. 충전 스위치는 구독이 없어 주기적으로 조회합니다.
- 남은 충전 시간. SDK가 주지 않는 것으로 확인했습니다. 잔량 변화 속도와 목표 잔량으로 추정하며, 잔량이 늘지 않아 추정할 수 없으면 타이머로만 동작합니다.
- 주차 브레이크. Brake 그룹은 브레이크 페달만 제공합니다. 주차 브레이크는 AAOS 속성을 읽을 수 있을 때만 확인합니다.
- 비공개 표시 API. Gear와 Odometer(주행 가능 거리)는 SDK에서 비공개·Deprecated로 표시돼 있으나 호출은 가능합니다. 읽기 실패 시 AAOS 속성으로 대체하며, 값을 읽지 못하면 기어 P 미확인으로 보아 세션을 시작하지 않습니다.
- 시트 등받이 제어. 목표 위치를 지정하는 API가 없어, 앱이 위치를 보면서 목표에서 정지시킵니다. 타임아웃과 도어 열림 때도 정지를 보냅니다.
- 탑승자 감지. Seat 그룹에 착좌 조회·구독이 있으나 사람만 감지할 수 있고 짐은 감지하지 못합니다. 그래서 착좌 값과 상관없이 시트를 움직이기 전에 사용자에게 사람이나 짐이 있는지 음성으로 확인합니다.
- 검증 상태. 위 API 시그니처와 권한은 SDK 공개 소스와 바이너리 선언으로 확인했습니다. 에뮬레이터에서의 실제 동작(시트 제어, AAOS 속성 값 등)은 개발 과정에서 확인합니다.

## 6. 개발 계획

1차 접수(11/15)까지 핵심 흐름이 도는 프로토타입을 내고, 2차 PT 심사(12/3~4) 전까지 실제 동작하는 앱을 완성합니다.

### 개발 환경

- Android API 28 이상, Gradle 8.0 이상, Kotlin, Jetpack Compose
- Pleos Connect SDK(Vehicle 2.3.2, SpeechToText 3.3.1, TextToSpeech 3.3.1)와 Pleos Connect Emulator 2.1.0 (Android 14/API 34, Android Studio AVD, cold boot)
- 화면 기준: 2,560×1,440 가로 화면. Pleos 개발용 기기 규격은 17인치 2,560×1,440이고, 에뮬레이터 기기 정의는 12.8인치 2,560×1,440(160dpi)입니다. 두 규격에서 모두 확인합니다.

## 7. 사업성

차지냅의 시장은 Pleos Connect를 탑재한 전기차이며, 충전할 때마다 차가 먼저 제안하는 구조라 별도 마케팅 없이 반복 사용이 일어납니다.

### 시장 규모

- 국내 전기차 누적 등록은 2026년 6월 말 109만 5,218대입니다.
- Pleos Connect는 2026년 5월 더 뉴 그랜저에 처음 적용됐고, 현대자동차그룹은 2030년까지 약 2,000만 대로 확대할 계획입니다(머니투데이, 2026.04).

### 예상 MAU

MAU는 "Pleos Connect 탑재 전기차 수 × 월 1회 이상 급속 충전 비율 × 설치율 × 설치자 중 월간 사용 비율"로 산정합니다. 아래 입력값은 모두 팀의 가정이며, 제출 전 근거를 보완해야 합니다.

| 시점 | 탑재 전기차 (가정) | 급속 충전 비율 (가정) | 설치율 (가정) | 월간 사용 비율 (가정) | 예상 MAU |
| --- | --- | --- | --- | --- | --- |
| 출시 1년 차 | 10만 대 | 60% | 15% | 50% | 4,500명 |
| 출시 3년 차 | 50만 대 | 60% | 20% | 50% | 30,000명 |

### 리텐션 목표와 수단

30일 리텐션 35%를 목표로 합니다.

- 자동 제안. 충전을 시작하면 앱을 열지 않아도 제안이 뜨므로, 충전 습관이 곧 사용 습관이 됩니다.
- 휴식 리포트. 주간 휴식 횟수와 시간을 보여 줘 꾸준한 사용을 유도합니다.
- 모드 확장(계획). 명상·스트레칭·집중 모드로 낮잠을 원하지 않는 날에도 쓸 이유를 만듭니다.
