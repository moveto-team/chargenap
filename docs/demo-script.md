# 시연 영상 대본

길이 약 1분 40초. 화면 녹화 + 내레이션. 데모 모드(60배속, `DEMO` 배지 표시)로 찍으면 20분 세션이 20초에 재생된다.
에뮬레이터에서 실제 SDK 경로로 찍을 때는 아래 "실제 SDK로 찍을 때" 참고.

## 촬영 준비

1. Pleos Connect 에뮬레이터(2,560×1,440) 실행 → `adb install -r apk/<팀명>_ChargeNap_release.apk`
2. 앱 실행 → 설정 → **데모 모드 켜기** (Vehicle Service가 없는 기기에서는 자동으로 데모 모드)
3. 녹화: `adb shell screenrecord --size 2560x1440 /sdcard/chargenap.mp4` (최대 3분) 또는 Android Studio의 Record
4. 앱을 다시 실행하면 3초 뒤 가상 충전이 시작된다. 그 직전에 녹화를 시작한다.
5. 제안 카드는 60배속에서 약 18초 동안 떠 있다(남은 충전 시간이 10분 미만이 되면 거둔다). 놓쳤거나 다시 찍을 때는 화면 위 "DEMO 조작" → [충전 시작]을 누르면 52%부터 새 충전이 시작되고 제안이 다시 뜬다.

## 실제 SDK로 찍을 때 (에뮬레이터 + Virtual Console)

데모 모드를 끄고, `adb forward tcp:8088 tcp:8088` 후 브라우저 `http://127.0.0.1:8088/`의 Virtual Console로 차량 값을 바꾼다.

| 보여 줄 것 | Virtual Console 조작 |
| --- | --- |
| 충전 감지 → 제안 | Gear Selection = P, Charge Switch = On, Battery SOC를 1%씩 두세 번 올린다(잔량 변화 속도로 남은 시간을 추정한다) |
| 공조 프리셋 적용·복구 | 세션 시작 후 Climate의 Target Temperature·Fan Speed가 바뀌고, 기상 후 원래 값으로 돌아오는 것을 화면 분할로 보여 준다 |
| 도어 열림 중단 | Door Position → 운전석 Open |
| 기어 변경 중단 | Gear Selection → D |
| 충전 중단 조기 기상 | Charge Switch → Off |

실제 길이(20분) 세션은 영상에 담기 어렵다. 실제 SDK 장면은 "제안이 뜨는 순간"과 "공조 값이 바뀌는 순간", "도어 열림 중단"만 짧게 찍고, 전체 흐름은 데모 모드 장면을 쓴다.

## 2차 PT 현장 시연 순서 (약 3분)

1. (30초) 문제 제기 한 장 → 앱 홈. 실제 SDK 모드(배지 없음)에서 Virtual Console로 Charge Switch On → 제안이 뜨는 것을 보여 준다.
2. (40초) 수락 → 안전 확인 → [없어요] → Virtual Console의 Target Temperature·Fan Speed가 바뀌는 것을 함께 보여 준다.
3. (30초) Door Position Open → 즉시 중단·안내 → 닫으면 복구. Gear D → 즉시 중단.
4. (60초) 설정에서 데모 모드를 켜 60배속으로 전체 흐름(제안→수면→5분 더→기상→브리핑→리포트)을 한 번에 보여 준다. "지금은 가상 차량"임을 말한다.
5. (20초) 차종별 미지원 대응(시트 미지원이면 공조와 사운드만), 사업성 한 줄로 마무리.

대비책: 에뮬레이터가 느리거나 Virtual Console이 안 열리면 4번(데모 모드)만으로 시연하고, 1~3번은 준비한 녹화 영상으로 대체한다.
