# 시연 영상 대본

제출한 시연 영상(2분 2초, 1920×1080 60fps, 한국어 내레이션)의 구성과 2차 PT 현장 시연 순서입니다.
영상 파일은 [GitHub Releases v1.0.0](https://github.com/moveto-team/chargenap/releases/tag/v1.0.0)에 있습니다.

## 만드는 방법

- **앱 장면**: 실제 앱 화면 코드(Jetpack Compose, 동작별 애니메이션 포함)에 세션 상태를 시간 순서대로 넣으며 30fps로 연속 캡처했습니다(`app/src/test/java/com/chargenap/app/ui/DemoVideoClips.kt`). 손으로 그린 목업이 아니며, 화면의 `DEMO` 배지와 화면 아래 "실제 앱 화면 · 데모 모드(가상 차량)" 표기가 그대로 보입니다. 상태 순서는 세션 엔진의 실제 흐름과 같습니다(예: 남은 시간을 모를 때 "얼마나 쉴까요?"를 먼저 제안하고, 잔량 변화로 시간이 계산되면 "20분 파워냅 어때요?"로 바뀜).
- **음성 조작 장면**: 음성 명령에 따른 앱 반응(5분 연장 안내, 기상)을 재현한 화면입니다. 개발 PC의 에뮬레이터에 온디바이스 음성 엔진이 없어 음성 인식은 실행 검증하지 못했으므로, 화면 아래에 "음성 명령 결과를 재현(음성 엔진은 실차 검증 전)"이라고 적었습니다.
- **모션 그래픽**: 도식·아이콘·숫자·전환은 코드로 그린 캔버스 애니메이션입니다. 화면 요소는 내레이션의 해당 단어가 들리는 순간에 맞춰 나타납니다.
- **내레이션**: ElevenLabs "Jian - Calm Korean Narrator" 음성(문장별 2테이크 중 선택). 음악과 효과음은 코드로 합성했고 -14 LUFS로 맞췄습니다.

```bash
# 앱 클립 (app/build/demo-clips/<장면>/f*.png + clip.json: 사건 시각·터치 위치)
./gradlew testDebugUnitTest --tests "com.chargenap.app.ui.DemoVideoClips" -Pchargenap.video=true
```

내레이션 문장: [docs/video/film-narration.txt](video/film-narration.txt)

## 2차 PT 현장 시연 순서 (약 3분)

준비: Pleos Connect Emulator(RAM 4GB, cold boot)에 release APK 설치, `adb forward tcp:8088 tcp:8088`, 브라우저에 Virtual Console.

1. **(30초) 문제 제기** — 문제 카드 한 장 → 앱 홈.
2. **(60초) 실제 차량 연동** — Virtual Console에서 Gear P, Charge Port Open, Charge Switch On, Battery SOC를 1%씩 올림(`scripts/vconsole.sh`로도 가능) → 홈에 잔량과 제안이 뜸 → [시작] → [없어요] → Virtual Console의 Seat Backrest·Target Temperature·Fan Speed가 바뀌는 것을 함께 보여 줌.
3. **(30초) 안전** — Door Position Open → 즉시 중단·안내 → Closed → 복구. Gear D → 즉시 중단·복구.
4. **(45초) 데모 모드 전체 흐름** — 설정에서 데모 모드를 켜고(30배속) 제안 → 수면 → 기상 → 브리핑 → 리포트를 한 번에. "지금은 가상 차량"이라고 말한다.
5. **(15초) 마무리** — 차종별 미지원 대응(시트 미지원이면 공조·소리만), 사업성 한 줄.

대비책: 에뮬레이터의 차량 서비스가 준비되지 않으면(개발 PC에서 관찰된 증상: `car_service not ready`) 앱은 사유를 표시하고 데모 모드로 동작한다. 이때는 4번만으로 시연하고, 2·3번은 이 시연 영상으로 대신한다.
